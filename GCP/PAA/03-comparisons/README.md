# 03-comparisons — Head-to-Head Decision Matrices

Six comparison files (~1,255 lines) for the exam's recurring
architectural choices — each a multi-column decision table plus
explicit "use X when... / don't use X when Y wins" tradeoff writeups
and an ASCII decision tree.

| File | Comparison |
|---|---|
| `01-low-code-vs-custom-development.md` | Agent Designer/CX Agent Studio (low-code) vs. ADK custom development |
| `02-orchestration-pattern-options.md` | Parallel vs. sequential vs. graph workflow |
| `03-a2a-vs-mcp-vs-direct-integration.md` | A2A (agent-to-agent) vs. MCP (agent-to-tool/data) vs. direct integration |
| `04-agent-hosting-deployment-options.md` | Agent Runtime vs. Cloud Run vs. GKE |
| `05-evaluation-approaches.md` | ADK evalset vs. Agent Platform Gen AI evaluation service vs. custom autoraters |
| `06-security-governance-models.md` | PAB/Agent Identity vs. Agent Gateway vs. Model Armor |

The compressed, at-a-glance version of these same 6 decisions lives in
`../00-START-HERE/DECISION-TREES.md` — use that for exam-day recall,
this folder for the full reasoning.
