## Exam facts

- **Code:** PAA
- **Status:** BETA — registration opens 2026-09-03
- **Format:** TWO required parts, must pass both — a proctored
  multiple-choice exam (~80 questions, 3 hours) and separate hands-on
  labs (Google Skills platform)
- **Pass score:** not publicly disclosed
- **Cost:** $120 USD beta (40% off $200 USD retail) + tax
- **Validity:** 1 year
- **Prerequisites:** none formal; recommended 3+ years cloud experience,
  including 1+ years building agentic solutions on Google Cloud
- **Sections and weights** (5 sections, verbatim from the official exam
  guide — see `00-START-HERE/RUNBOOK.md` §3 for the full task
  breakdown):

  | # | Section | Weight |
  |---|---|---|
  | 1 | Building agents using low-code tools | ~13% |
  | 2 | Using coding agents for application development | ~17% |
  | 3 | Developing custom agents | **~33%** |
  | 4 | Evaluating and deploying agentic workflows | ~22% |
  | 5 | Securing and governing agentic workflows | ~15% |

- **In-scope tools:** 28, verbatim from the guide — see
  `00-START-HERE/SERVICE-MATRIX.md`
- **Capstone project:** `05-labs/lab-07-capstone-realtime-agentic-project.md`
  — a ground-zero, end-to-end real-world project spanning all 5 sections
