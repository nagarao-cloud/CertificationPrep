# 01-domains — Per-Section Deep Dives

One file per exam section (5 files, ~3,920 lines), each internally
structured around that section's real task numbers from the exam
guide. Depth is weighted to match each section's actual exam weight —
Section 3 runs noticeably longer than the others.

| File | Section | Weight | Tasks |
|---|---|---|---|
| `SECTION-1-low-code-tools.md` | Building agents using low-code tools | ~13% | 1.1, 1.2 |
| `SECTION-2-coding-agents.md` | Using coding agents for application development | ~17% | 2.1, 2.2 |
| `SECTION-3-custom-agents.md` | Developing custom agents | **~33%** | 3.1, 3.2, 3.3 |
| `SECTION-4-evaluate-deploy.md` | Evaluating and deploying agentic workflows | ~22% | 4.1, 4.2 |
| `SECTION-5-secure-govern.md` | Securing and governing agentic workflows | ~15% | 5.1, 5.2 |

Each file explains every named tool from its section in depth, includes
comparison/decision content and ASCII diagrams, pairs every "use X"
claim with a stated tradeoff, and ends with section-specific practice
questions (every option explained inline). Start here for first-time
learning; use `02-services/` for per-tool lookup and `03-comparisons/`
for head-to-head decisions once you've read the relevant section.
