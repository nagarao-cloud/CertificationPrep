# 06-practice — Question Banks and Mock Exams

Seven files (~3,900 lines): 5 per-section question banks plus 2 full
mock exams, all scenario-based (matching the real exam's system-design
framing) with every answer option — right and wrong — explained inline
immediately after its question. No separate answer key, so numbering
can't drift.

| File | Questions | Notes |
|---|---|---|
| `section-1-questions.md` | 15 | Building agents using low-code tools |
| `section-2-questions.md` | 18 | Using coding agents for application development |
| `section-3-questions.md` | 30 | Developing custom agents — proportionally the largest bank, matching its ~33% weight |
| `section-4-questions.md` | 22 | Evaluating and deploying agentic workflows |
| `section-5-questions.md` | 16 | Securing and governing agentic workflows |
| `mock-exam-1.md` | 80 | Matches the real exam's full format (~80 Q, 3 hrs), sections proportionally distributed |
| `mock-exam-2.md` | 40 | Shorter drill, same proportional distribution, no wording overlap with mock-exam-1 or the section banks |

At least one question in Sections 3/4 and both mocks specifically tests
the Agent Runtime/Agent Search rename — the single highest-value trap
in this folder.
