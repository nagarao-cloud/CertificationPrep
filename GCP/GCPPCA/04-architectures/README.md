# 04-architectures

All 4 official case studies (EHR Healthcare, Helicopter Racing League,
Mountkirk Games, TerramEarth) with reference architectures, primary
constraints, question patterns, and a case-specific exam trap each —
plus 2 generic patterns (multi-region web app, data/analytics
pipeline) for scenarios that don't map to a named case study. Case
studies are 20–30% of the real exam; read these before attempting
`06-practice/mock-exam-1.md` / `mock-exam-2.md`.
